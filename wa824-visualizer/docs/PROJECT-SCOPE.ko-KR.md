# 공개 저장소의 범위와 기여 구분

이 저장소는 WA824 ISA용 개발 도구이자 **CPU 플러그인 시각화 플랫폼**입니다. 학생의 CPU 구현을 대신 게시하는 장소가 아닙니다.

| 대상 | 이 저장소 | 기여 표현 |
|---|---|---|
| UI / 렌더러 / 로컬 서버 / CPU 플러그인 API | 포함 | 공용 비주얼라이저 개발 |
| C 부분집합 컴파일러 / 어셈블러 / ECALL 호스트 | 포함 | 개발 도구 구성 |
| JS 참조 CPU | 포함 | 호환성 기준 / 실행 예제 |
| Verilog 멀티사이클 CPU 데모 | 포함 | 도구 번들 예제 (학생 구현과 무관) |
| 학생의 SystemC CPU 및 5단계 파이프라인 CPU | **미포함** | 학생의 별도 저장소에서 관리 |
| 학생의 draw.io 원본 / ISA 원본 문서 | **미포함** | 설계자 권리 확인 후 별도 공개 |
| 특정 학생 CPU용 Adapter | **미포함** | 실제 작성자/공동 작업자 명기 후 별도 배포 |

따라서 학생 시연 시에는 **'학생이 설계한 CPU'**와 **'외부에서 제공된 도구/어댑터'**를 구별해야 합니다. 이 저장소는 학생이 모든 구현을 직접 했다는 증명 자료가 아니며, 모든 학생 CPU와 자동 호환되는 것도 아닙니다.
