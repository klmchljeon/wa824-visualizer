# GitHub 업로드 전 체크리스트

1. 이 폴더의 코드에 대한 공개·재배포 권리를 확인하세요. 기본 MIT `LICENSE`는 게시자가 적절한 권리를 가진 코드에 대해서만 적용할 수 있습니다. 기여자 이름 또는 저작권 표시를 실제 상황에 맞게 정리하세요.
2. **학생의 SystemC CPU, draw.io 원본, 비공개 ISA 원문은 이 ZIP에 없습니다.** 공개 동의 없이 추가하지 마세요.
3. GitHub에서 `wa824-visualizer` 등 새 저장소를 생성하고, ZIP 내부 폴더의 내용물을 루트에 올리세요. `.gitignore`와 `LICENSE`도 함께 업로드합니다.
4. Windows의 `start.bat`로 기본 JS reference CPU가 실행되는지 확인하세요. 자세한 절차는 `README.md` 및 `docs/INSTALL-WINDOWS.ko-KR.md`에 있습니다.
5. README의 지원 범위·개발 기여 구분·지원하지 않는 기능을 유지하고, 학생 코드까지 함께 만든 것처럼 표시하지 마세요.

참고: GitHub 페이지의 'Code → Download ZIP'은 이 저장소의 소스코드 다운로드 기능입니다. 이 웹 앱은 Python 로컬 서버 API가 필요하므로 **GitHub Pages만으로 실행되지 않습니다.**
