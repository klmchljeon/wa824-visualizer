# WA824 ISA 호환 개요 (비주얼라이저 기준)

이 문서는 **도구 연동에 필요한 호환 조건**을 요약한 것입니다. 학생이 작성한 ISA 원문을 재배포하지 않으며, 원 설계 전체를 대신하지 않습니다. 인코딩 관련 세부 결정은 [`ISA-DECISIONS.md`](ISA-DECISIONS.md)를 확인하세요.

- 명령어: **24비트 고정**, 메모리에 **little-endian** 3바이트 저장.
- 일반 PC 증가량: **3바이트**. 분기·점프는 ISA 규칙에 따라 PC 변경.
- 레지스터: 16비트 `Wx0`~`Wx7` 총 8개. 하위·상위 바이트 `xNl`,`xNh`를 별도로 접근할 수 있습니다.
- 참조 CPU 관례: `x0`은 읽기 0 / 쓰기 무시.
- ISA 명령 형식: `R`, `I`, `L`, `S`, `B`, `JA`, `JR`, `JRP`, `SYSTEM`.
- 주로 사용하는 명령: `ADD`, `SUB`, `AND`, `OR`, `XOR`, 시프트, 비교, 즉시값 연산, `L/S`, `BEQ/BNE/BLT/BLTU`, `JA/JR/JRP`, `ECALL/EBRAKE`.
- `SL/SLI`, 상세 `MRET` 및 예외 처리 등은 완전히 정의되지 않았습니다. 임의로 ISA 의미를 확장하지 마세요.
- C 실행은 [`ABI-IO.md`](ABI-IO.md)에 정의한 **시뮬레이터 전용 ABI와 ECALL 서비스**를 사용합니다.

기존 설계 자료의 배포 권리는 원 저작자에게 있으므로, 원문 ISA 및 학생 draw.io는 **본 저장소에 동봉하지 않았습니다**. 새 CPU 구현은 이 도구의 어셈블러·참조 CPU와 결과를 비교해 호환성을 검증하는 것을 권장합니다.
